# Ledger Dashboard 设计与 skill 交付契约

## 定位

用户调用 skill 后，自动生成并打开一个本地交互式 HTML 驾驶舱。默认先呈现账号额度与近期消耗；通过时间 → 项目 → 任务 → 调用逐层定位。当前 index.html 是可操作的设计原型，所有明细为确定性合成数据，尚未连接统计引擎。

## 视觉系统

- 方向：精密测量仪表，而非营销落地页。深海蓝背景 #0B1420、面板 #111E2D、分隔 #243548、冰蓝 #76CEEB、暖琥珀 #EDB478、正文 #E4EDF5。
- 数字使用 SF Mono / Consolas 等宽体；中文使用苹方 / 微软雅黑。标题 30px，核心指标 30px，正文与数据注释按密度分级。字体全部本地回退，无外部加载。
- 视觉主角：双额度刻度环与可交互堆叠时间线。缓存输入、非缓存输入、输出采用固定语义配色；额度提醒使用琥珀。
- 4px 间距基准；内容区 18px 模块间距；14px 面板圆角；分隔线取代重阴影。
- 动效：模块 600ms 轻入场、额度环 1.2s 绘制、柱形交错生长、详情抽屉 300ms。无持续旋转或假实时闪烁。支持系统减少动态效果与手动关闭。
- 原型提供深色与浅色主题，以及窄屏布局。侧栏在窄屏变为紧凑导航，表格局部横向滚动。

## 信息层级

1. 账号层：五小时 / 每周额度、实际重置时间、数据采样时间。始终保持全局口径。
2. 分析层：时间、项目、任务组合筛选，以及当前范围说明。
3. 指标层：本机 token 总量、非缓存输入、缓存命中率、活跃任务与调用次数。
4. 模型层：在首页醒目位置使用左右双榜比较各 GPT 模型。左侧默认按“估算 Credits / 模型调用次数”展示额度消耗强度，并可切换为输出生成速度（token/s）；右侧按 token 总量排行。顶部同时展示额度强度、估算额度总量、生成速度和缓存效率的领先模型。
5. 趋势层：按日 token 堆叠图和构成图。点击某天切到自定义单日范围。
6. 归因层：项目分布与任务表。项目列表保留当前时间范围内所有项目，便于切换对比，任务筛选不改变该列表口径。
7. 调用层：任务详情抽屉列出当前日期范围内每次调用的时间和输入/输出。

## 交互契约

- 时间、项目和任务改变后，指标、时间线、构成和任务列表联动。
- 模型双榜跟随时间、项目和任务筛选。额度消耗强度定义为 `按官方模型 Credit token rate 估算的 Credits / 模型调用次数`。估算 Credits 分别对非缓存输入、缓存输入和输出使用对应费率；它用于比较模型消耗强度，不冒充账户五小时或周窗口的精确百分比差值。
- 生成速度定义为 `该模型可测速调用的输出 token 总量 / 这些调用的模型生成持续秒数`，显示为 token/s。正式版只有在能取得模型生成持续时间时才计算；不能把整段任务时长、工具执行时长或额度下降速度标记为生成速度。
- 左侧额度/速度榜与右侧总量榜始终同时显示，使用各自独立比例尺。额度榜补充估算 Credits 总量与 token/s，速度榜展示有效测速调用数，总量榜展示当前范围占比和调用次数。
- 账号额度不随筛选改变；项目分布仅受时间影响。正式版在项目分布处显示“当前时间范围 · 所有项目”说明。
- 项目切换清空不适用的任务筛选；点击已选项目可取消。重置恢复近七天、所有项目和任务。
- 搜索仅作用于任务表，不影响上方整体指标；表格支持总量正反排序和分页。
- 详情打开后锁定背景滚动；支持 Escape、点击遮罩关闭及焦点返回。
- 数据说明页明确展示合成/真实模式、观测边界、统计规则。
- 空状态解释如何调整条件；缺失额度显示未知，绝不填入演示值。

## 正式 skill 的运行流程

“打开我的 Codex 用量驾驶舱” → 本地增量解析 → 校验与汇总 → 取得可用额度快照 → 将经过白名单筛选的数据注入固定 HTML 模板 → 写入用户本地报告目录 → 在 Codex 浏览器打开 → 聊天只返回入口与必要提示。

HTML 是首要交付物，聊天文字作为入口。每次调用沿用模板与统计脚本，不让模型重新生成页面代码。按需生成的页面是静态数据快照，页面筛选完全在本地执行；再次调用 skill 才更新数据，不把普通 HTML 假装成实时监控。

正式版建议数据接口包含 report_meta、coverage、quota_snapshots、projects、tasks、usage_by_day 和调用摘要。quota_snapshots 与局部筛选数据彻底分离。大量逐次记录使用本地分页或按任务生成详情，避免把全年完整日志塞进 HTML。页面不携带提示词、工具输出、密钥和完整本地路径。

额度刷新契约：页面优先调用 `window.ledgerRefreshAdapter()`，其次加载同目录的 `quota-snapshot.local.js`（适配 `file://` 预览），最后读取 `quota-snapshot.local.json`。启动阶段会用带时间戳的同步请求重新读取本地 JS 快照，并在首轮渲染时写入额度卡片，避免缓存脚本或渲染时序让旧快照重新出现。JS 快照通过 `window.__CODEX_QUOTA_SNAPSHOT__` 注入；JSON 与 JS 快照至少包含 `five` 与 `week` 两个窗口，每个窗口提供 `used`（0–100）、`resetsAt`（推荐）或 `seconds`（距离重置的秒数）和 `source`（正式数据使用 `live`）。刷新成功后页面把最新快照写入 `localStorage`，重开报告时优先恢复 `observedAt` 更新的快照，避免回到旧数据；宿主运行时也可注入 `window.ledgerPersistQuotaSnapshot(snapshot)` 将数据写回磁盘。若浏览器禁用本地存储且没有宿主持久化桥接，页面保留上次观测值并明确显示“额度快照未变化”，不把 Token 日志推算成官方账户额度。正式 Skill 每次生成报告时覆盖本地 `quota-snapshot.local.js`，刷新按钮重新加载该文件并据 `resetsAt` 计算最新倒计时。个人快照文件已列入 `.gitignore`，不要提交到公开仓库。

## 首版页面与后续增强

当前原型已经支持：时间快捷筛选、自选日期、项目/任务联动、GPT 模型额度强度/输出 token/s 与总量双榜、模型 × 项目热力图、任务异常分布、点击日期下钻、任务搜索、排序、分页、任务抽屉、深浅主题、减少动态效果和图片导出。原型中的调用持续时间与账户额度为确定性合成数据；Credits 使用公开费率计算。
导出视图使用 Canvas 原生绘制 PNG 分享卡片，包含右侧主数据区的核心指标，并在图片底部保留醒目的 Ledger 品牌与 GitHub 项目地址；不依赖 SVG 或 foreignObject。

接入真实数据时补齐：当前官方五小时 / 周窗口筛选、小时级时间线、格式及覆盖诊断、历史额度曲线、模型维度筛选、选择区间拖拽刷选、大量数据虚拟列表、筛选状态持久化。额度曲线不能虚构；缺少连续快照时保留断点。

发布前的关键验收：真实数据对账、响应式多尺寸实际测试、键盘完整路径、导出脱敏、超大日志性能。当前已在浏览器核对默认显示、项目/任务筛选、日期下钻、任务抽屉、搜索空状态和主题切换；控制台未发现错误。尚未完成真实日志接入、正式 skill 封装或 GitHub 发布。
